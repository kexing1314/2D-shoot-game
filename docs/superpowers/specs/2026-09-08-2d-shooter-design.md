# 2D 联机射击小游戏 · 设计文档

日期：2026-09-08
状态：已与需求方逐节确认

## 1. 需求汇总

- 网页运行的 2D 平面射击小游戏，联机可玩
- 房间码进房，每房 2–4 人
- PvP + 打怪混合：同场有其他玩家和怪物，可互相攻击
- 操作：WASD 移动，方向键四向射击
- 血条 + 无限重生 + 击杀计分，无胜负结算，休闲局；HP 脱战 3 秒后缓慢恢复
- 地图较大、视野有限（镜头跟随）、右上角小地图（雷达：显示全部玩家和怪物）
- 小 Boss 刷新在地图固定的空旷区域
- 固定墙体障碍（挡移动、挡子弹）
- 小 Boss 定时刷新，击杀后掉落强化武器
- 几何图形画风，零美术素材
- 先跑本机/局域网，后续部署云服务器（不同 WiFi 的人可玩）
- 只做朋友休闲局，不做防挂加固

## 2. 技术方案（已选定：方案 A）

**纯 Node.js + ws + 原生 Canvas，权威服务器。**

- 服务器是唯一真相：全部游戏状态（位置、HP、子弹、怪物、Boss、拾取物、分数）只在服务器上计算
- 客户端只做两件事：把按键状态发给服务器；把服务器广播的状态画到 Canvas
- 一个 Node 进程同时提供：`node:http` 静态托管（大厅页 + canvas 页）+ 同端口升级 WebSocket。不用 express，不用打包工具
- 唯一 npm 依赖：`ws`

已否决的备选：
- Phaser 引擎：几何图形用不上引擎，联机部分照样要自己写
- WebRTC P2P：仍需信令服务器，NAT 不稳定，主机掉线全灭

## 3. 文件结构

```
game/
├── package.json     # 唯一依赖：ws
├── server.js        # HTTP托管 + WebSocket + 房间管理 + 游戏模拟循环
├── shared.js        # 双端共享：地图墙布局、全部数值常量、武器表
├── test.js          # 纯逻辑 assert 测试（node test.js 直接跑）
└── public/
    ├── index.html   # 大厅界面 + 游戏 canvas
    └── client.js    # 按键采集、镜头、渲染、HUD
```

`shared.js` 浏览器端用 `<script src>` 直接引入，地图和数值只写一份，双端永不分叉。

## 4. 服务器游戏模拟

固定帧率 **30 tick/s（33ms）**（云端联机后从 20Hz 上调，降体感延迟），每 tick 顺序：读按键 → 移动玩家 → 移动子弹/怪物/Boss → 碰撞结算 → 刷怪 → 全量广播 `state`。

### 4.1 地图（多地图，数据驱动）

- **地图表 `MAPS`**（shared.js）：加地图 = 加一项，含 name/floor(地砖 key)/w/h/walls/playerSpawns/bossSpawns。首发四张：草地要塞 4800×2700（中央十字堡垒+四象限 L 掩体）、沙漠废墟 4800×2700（中央环形废墟留门洞）、冰原站台 4200×2400（三道横墙夹双长廊）、陶土峡谷 5200×2600（交错断墙蛇形通道）
- 房主创建房间时选图（`create` 带 map key，非法值回退默认草地），房间全程使用该图；服务器/客户端所有地图读取走 room.map / curMap
- 布局约束由 test.js 断言把关：墙不越界、Boss 刷新点距墙 >150px、玩家刷新点不贴墙
- 画风：地面 = 同包 CC0 地砖 pattern（草/沙/冰/陶四主题）；**墙材质随主题**（苔石+石缝 / 砂岩+裂纹 / 冰块+冰裂 / 土坯+土坑，主体+暗描边+左上高光+种子细节纹），可破坏墙恒为木箱色；种子散布无碰撞装饰 props（灌木/木箱/桶）；小地图墙色跟主题
- 玩家 = 半径 16 的圆；碰撞用圆 vs 矩形，X/Y 轴分开解算（撞墙贴墙停下）
- **墙分两类**：地图初始墙 = 不可破坏（敌人 A* 绕路）；可破坏墙（`destructible: true` + hp，敌人啃穿、被啃穿即移除并广播消失）——地图初始不生成可破坏墙，结构为玩家放置墙预留；墙存每房间副本（room.walls），地图模板不可变；可破坏墙随 state.walls 广播（不可破坏墙客户端直接用模板，不广播）

### 4.2 移动与射击

- 玩家 HP 100，移速 200 px/s；服务器存按键状态，每 tick 积分位移
- **HP 缓慢恢复**：每秒 +2，回满 100 封顶。**受伤打断恢复**：服务器为每个玩家记 `lastDamagedAt`，距最近一次受伤满 **3 秒**后才重新开始恢复。恢复速率与延迟时长在 `shared.js` 可调
- **低血肾上腺素**：HP 低于 50 时每次受伤获得 3 秒移速 +30%（260 px/s），再受伤刷新时长不叠加；客户端画蓝色残影+脉冲圆环提示（boost 字段广播）
- 方向键开火，两键同按合成斜向射击（←+→ 等对键互相抵消不开火），射速由武器表决定（默认手枪 300ms/发，按住连发同速率）
- 子弹属性完全由武器表驱动；碰墙或出图即消失；**穿透**：武器带基础穿透数（手枪 1/机枪 2/霰弹 3/火箭 0），子弹最多命中 `1 + 穿透数×等级档`（5 级 ×2 / 10 级 ×3 / 15 级 ×4）个目标后消失，爆炸弹命中即爆不占穿透
- **碰撞体积**：玩家×玩家、玩家×敌人互不可穿过，重叠一律各退一半（**双向互挡**：怪朝玩家顶时玩家也挤不开怪，身体封锁是双向的，带撞墙检测）；怪×怪不碰（怪潮堆叠是特色）

### 4.3 武器表（数据驱动，加武器 = 加一行）

```js
const WEAPONS = {
  pistol:  { rate: 300, dmg: 25, speed: 1500, count: 1, pierce: 1, size: 3, range: 600, mag: 12, reloadMs: 1500 },
  mg:      { rate: 100, dmg: 15, speed: 1500, count: 1, pierce: 2, size: 3, range: 500, mag: 40, reloadMs: 2600 },
  shotgun: { rate: 600, dmg: 20, speed: 1500, count: 5, spread: 15, pierce: 3, size: 3, range: 400, mag: 5, reloadMs: 2200 },
  rocket:  { rate: 1500, dmg: 30, speed: 1050, count: 1, pierce: 0, size: 8, range: 700, explode: 100, explodeDmg: 50, mag: 1, reloadMs: 3000 },
}
```

- 射击逻辑只写一次：读表生成子弹（count>1 时以射击方向为中心 ±spread 度扇形展开）
- 子弹**子步进推进**：每 tick 按弹速拆成 ≤12px 的小步逐步做墙/实体判定——1500px/s 弹每 tick 飞 50px 大于命中窗口，不拆步会穿模漏判
- pierce=true 的子弹穿过怪物和玩家不消失，撞墙才消失
- range = 子弹最大飞行距离（px），飞满即消失；霰弹枪贴脸爆发
- **火箭筒爆炸弹**（替代加农炮）：命中任何目标/撞墙/飞到终点都引爆，对半径 100px 内目标造成 50 点 AOE 伤害 + 沿子弹射击方向击退，不伤射手自己；直击目标吃 30 直击伤 + 50 AOE 叠加。单发弹匣 + 3s 换弹 = 大空窗平衡。Boss 持火箭筒时爆炸只伤玩家（与 Boss 子弹只打玩家一致）；boom 随子弹广播爆炸半径数值（0=不爆），客户端据此画橙色冲击波圈——扩散到恰好实际伤害半径后淡出（所见即所伤）+ 爆炸粒子
- Boss 刷新时从表中随机选一个非 pistol 武器持有
- **换弹**：每把枪有弹匣 mag，每次开火（霰弹 5 颗算 1 发）消耗 1 弹药；打空自动换弹，R 键手动换弹（边沿触发，按住不连换）；换弹开始即补满弹药，reloadMs 期间不能开火（移动不受影响）；重生/拾取武器时弹匣补满、换弹中断；Boss 弹药无限（restMs 停火期即其天然换弹）

### 4.4 普通怪物

- **波次怪潮刷怪**（合作化轮）：第 N 波一次刷 `waveCount = min(14+8N, 100)×难度` 只（第 1 波 22、第 10 波 94、封顶 100 同场）；清完休息 4 秒掉 2 个补给再下一波；怪 HP ×(1+0.18(N-1)×难度)、速度 ×(1+0.04·min(N-1,8))；怪经验 `10+3(N-1)`、Boss `100+20(N-1)`（×难度）；首波建房 3 秒后；难度 diff 存 room（菜单选项预留，数量/HP/经验函数全乘它）
- **怪物类型**（MONSTER_TYPES）：normal 僵尸 / runner 疾行（0.7 体型、130 速、30 血，2 波起 20%）/ brute 重装（机器人壳 1.4 体型、250 血、25 碰伤，3 波起 10%）/ spitter 喷吐（远程慢速红弹 500 射程 2.5s 一发，4 波起 10%；怪物弹只打玩家）
- **精英怪**：5% 混入——血 ×4、体 ×1.25、伤 ×1.5、金环脉动标识，死亡必掉补给包
- **赶路速度分区**：与目标距离 > 1920px 速度 ×3、768–1920 ×2、≤768（=视野半宽 640×1.2，接战距离）恢复原速——怪潮跨图赶路不拖沓、贴脸压力不变
- **近战前摇**：怪进入接触范围先进前摇（客户端红闪脉动预警圈，state.monsters.w 标记），前摇结束仍在接触才结算伤害、否则落空，之后 1s 冷却；前摇时长 `max(50, 550-(N-1)×50)` ms——第 1 波 0.55s 可躲、第 11 波起 50ms 贴到必中；前摇期间怪继续追；普通怪碰伤 14
- 行为：**A\* 网格寻路**（60px 格，每怪限流 0.5s 重算+id 错峰）追最近的玩家（60 px/s）——不可破坏墙绕路、可破坏墙挡路站定啃穿（`MONSTER.wallDmgPerSec=30`）；无路径才直线；碰撞造成 10 伤害，之后 1 秒攻击冷却
- HP 50（默认手枪两发），死亡即消失

### 4.5 小 Boss

- **固定刷新点**：每张地图预设 3 个 Boss 刷新点（地图表 `bossSpawns`），刷新点所在区域墙体布局保持空旷（ Boss 场地 = 天然的 PvP 争夺竞技场）
- 每 25 秒刷一只：从当前没有 Boss 的刷新点中选离玩家最远的一个；若刷新点全被占则本轮跳过，场上同时最多 **3 只**
- Kenney 黑衣人精灵（持枪姿势），HP 450，移速缓慢 40，紫色光晕标识
- **持枪 Boss**：刷出时随机持有一把非 pistol 武器，头顶显示武器名
- 攻击逻辑：**视野 = 所持武器的射程**（火箭筒 Boss 视野 700 爆炸弹压制、霰弹枪 Boss 视野 400 逼玩家近战）。视野外 A* 绕路缓追最近玩家（与怪物同一套 stepAlongPath）；玩家进入视野后边逼近边按武器射速朝玩家精确角度开火（扇形/穿透全按武器表）。子弹可被墙挡、可躲
- **无碰撞伤害**（与普通怪定位区分：怪=近战杂兵，Boss=持枪精英）；Boss 子弹只打玩家，不打怪/其他 Boss，客户端画成红色便于躲避
- 死亡时在原地掉落**它手里那把武器**（想要火箭筒就猎火箭筒 Boss）

### 4.6 武器拾取物

- 旋转小方块，玩家碰到即拾取，替换当前武器
- 持有规则：**保留到死亡为止**，重生变回 pistol；玩家死亡时其武器掉落在死亡位置，可被任何人拾取（PvP 争夺点）

### 4.7 死亡、重生、计分

- HP ≤ 0 死亡，3 秒后在离其他玩家最远的刷新点重生，HP 回满
- 计分板两项：击杀（打死玩家算开枪者的，打死怪物/Boss 也算）、死亡
- 无胜负结算，随时可退，分数仅当局房间内有效

### 4.8 房间生命周期

- 创建房间 → 4 位房间码；输码加入 → 立即出生进游戏（无等待阶段）
- 玩家全退 → 房间及其模拟定时器销毁
- 断线 → 角色移除、分数清掉；重连输码即新角色进入（不做重连保分）

### 4.9 合作化 · 等级 · 护盾

- **友伤关闭**：玩家子弹穿过玩家、玩家爆炸不伤队友；仅 Boss 子弹/爆炸打玩家。击杀 = 杀怪+杀 Boss（合作内比枪法）
- **等级**：上限 **15 级**，约 30 分钟满级。进度 p=(L-1)/14，倍率：移速/伤害/护盾/弹速 ×(1+p)（满级 ×2）、换弹时长 ÷(1+p)（×2 快）、射击间隔 ÷(1+2p)（射速 ×3）。将来加属性只改 `shared.js` 的 `levelMul`
- **经验**：杀怪/杀 Boss **全场玩家同额**获得（合作核心）；升级需求 `30×L^1.35` 递增；怪经验随波次涨（见 4.4）
- **死亡惩罚**：等级减半（向下取整、最低 1）、经验清零；重生护盾按新等级回满
- **护盾**：独立蓝条垫在血前（伤害先扣盾），1 级 25 / 满级 50；未碎时脱战 3 秒后每秒回上限 1/10，**碎盾（被打到 0）后须不受击 20 秒才开始回**；医疗包回满血+盾；**升级瞬间护盾回满**；有盾时身体蓝环呼吸环绕（盾量越少越淡），碎盾瞬间蓝粒子爆+蓝冲击波环
- **受击僵持/击退分档**：无盾或这一下碎盾 = 0.75s 不能攻击 + 24px 击退；被盾挡下（盾没碎）= 0.4s + 12px；玩家打怪/Boss 同样的控制（怪击退 20px、Boss 10px，+0.75s 不能接触攻击/停火，可风筝）；**击退方向严格按子弹射击方向**：子弹直击与爆炸 AOE 都沿弹速向量、近战沿攻击者→受击者
- **补给拾取**：波间休息掉 2 个——医疗包（绿十字，血盾回满）/ 弹药箱（橙弹条，秒满弹）；与武器掉落共用 pickups（type 字段区分）

## 5. 网络协议（JSON over WebSocket）

客户端 → 服务器：

| 消息 | 时机 | 内容 |
|---|---|---|
| `create` | 点"创建房间" | `{t:"create", name, map}`（map = 地图 key，缺省/非法回退默认） |
| `join` | 点"加入房间" | `{t:"join", name, code}` |
| `input` | 按键变化时（keydown/keyup 触发才发） | `{t:"input", keys:{w,a,s,d,up,down,left,right,r}}` |
| `ping` | 每 2 秒 | `{t:"ping", ts}`，服务器回 `{t:"pong", ts}` 原样；客户端算 RTT 指数平滑后显示 |

服务器 → 客户端：

| 消息 | 时机 | 内容 |
|---|---|---|
| `joined` | 进房成功 | 玩家 id、房间码、玩家颜色、房间地图 key |
| `state` | 每 tick（30Hz） | 波次 wave + 休息倒计时 restIn；全部玩家（位置/HP/护盾 shield/等级 level/经验 xp/武器/弹药 ammo/换弹中 reloading/分数/死亡倒计时/射击朝向 face）、怪物（w=近战前摇标记）、Boss、子弹、拾取物（type：weapon/health/ammo）、可破坏墙 walls（仅存活的可破坏墙，带 id/hp）；实体均带 id（客户端按 id 匹配前后帧做插值与消失特效） |
| `error` | 房间码不存在 / 房间满 | 提示文本，客户端弹回大厅 |

全量广播，不做增量 diff、不压缩（2–4 人 + 20 怪 + 2 Boss，每次几 KB，diff 是负优化）。

## 6. 客户端

### 6.1 大厅页

- 昵称输入框
- **地图选择卡**：每张地图一张卡（小 canvas 画墙布局预览 + 地图名），点选高亮，建房时带上
- "创建房间"按钮 + 房间码输入框 + "加入房间"按钮（加入者跟随房主选的图）
- 创建/加入后立即进入游戏（无等待阶段），房间码在游戏画面顶部中央常显，便于转发给朋友

### 6.2 游戏画面

- Canvas 视口 **1280×720**，镜头跟随自己的角色，地图边缘处钳制不越界
- 绘制：墙（矩形 + 亮/暗边假 3D）、**玩家（Kenney Top-down Shooter CC0 俯视精灵小人：canvas 旋转到瞄准角实现任意朝向，姿势 hold/手枪/长枪/换弹 四态切换，走路颠簸代步态帧，地面投影+队伍色环辨识，头顶昵称+血条，自己描白边；精灵未加载完回退渐变球）**、怪物（同包 CC0 僵尸精灵：朝追击方向旋转 + 跑动颠簸 + 红色地面环）、Boss（同包机器人精英精灵：玩家 2 倍体型、常持仓枪姿势 + 紫色光晕 + 武器名 + 血条）、子弹（拖尾光条 + 光晕，玩家黄 / Boss 红，尺寸按武器表 size）、拾取物（旋转金方块 + 脉冲光环）、地面网格（随镜头滚动）
- 视野裁剪：只画镜头视口内的实体
- **客户端插值**：实体按 id 匹配前后两帧状态，按收包时长 / TICK_MS lerp，30Hz 广播呈现 60fps 平滑（画面落后一 tick，休闲局无感）
- **纯客户端粒子特效**（状态 diff 推测触发，零素材）：枪口闪光、命中火花、怪物/Boss/玩家死亡爆炸、拾取闪光；自己受伤时屏幕震动 + 红闪；粒子上限 300
- **战斗可读性**：Boss 锁定警戒线（最近活人进入其武器射程时画流动红虚线，停火期也显示）；玩家小炮管指向 face（服务器开火时记录）+ 开枪后坐 2px/100ms（客户端按新子弹位置推测射手）；常驻四角暗晕；HP<30% 红色呼吸脉冲警告

### 6.3 HUD

- **右上角小地图**（约 200×112）：全图缩放轮廓 + 墙体 + 全部玩家/怪物/Boss/拾取物位置点（雷达模式），Boss 为大紫点；小地图正下方显示**网络延迟**（ping/pong RTT 平滑值，绿 <60 / 黄 <120 / 红 ≥120 ms）
- **左上角计分板**：每个玩家的击杀/死亡
- **底部状态栏**：大血条 + 武器名与详情（伤害/射程/穿透/爆炸）+ 击杀/死亡 + 弹药 x/mag
- **换弹提示**：自己换弹中，头顶（昵称/血条上方）黄字闪烁"换弹中…"
- **波次信息**：顶中第二行「第 N 波 · 剩 X 只」（橙）/「下一波 X 秒」（金）
- **等级/护盾显示**：头顶昵称带 Lv 标签 + 血条上方护盾细蓝条；状态栏护盾蓝条 + 第二行等级与经验进度；升级时自己身上金色粒子爆；武器详情行穿透数按等级档实时显示
- **战斗预警特效**：怪近战前摇红闪脉动圈；有盾蓝环环绕、碎盾蓝爆+蓝环
- 死亡时屏幕中央显示"3 秒后重生"

## 7. 异常处理

- 房间码不存在 / 房间满（>4）→ `error` 消息 → 客户端弹提示回大厅
- 玩家断线 → 角色移除；重连重新输码
- 玩家全退 → 房间销毁，清理定时器，无僵尸房间
- 服务器重启 → 房间全部蒸发；客户端检测 WebSocket 关闭 → 弹"与服务器断开"回大厅。**不做状态持久化**

## 8. 部署

- 阶段一（本设计范围）：本机 `node server.js`，局域网朋友用 `ws://本机IP:端口` 加入
- 阶段二（后续，不在本期实现）：云服务器部署。同一份代码，前置要求只有 WSS（https 页面只能连 wss://）。两条路任选：Render/Fly.io/Railway 托管平台（TLS 自动），或 VPS + Caddy 反代（自动签证书）
- 不做防挂加固：协议只收按键状态，服务器自算一切，客户端无上报坐标的口子

## 9. 测试策略

- **纯逻辑**（碰撞、伤害、扇形展开、武器表读取）：`test.js`，assert 断言，`node test.js` 直接跑，无测试框架
- **联机行为**：本机起服务器，开两个浏览器窗口互射验证同步；再用第二台设备连局域网 IP 验证跨机器
- **手感数值**（移速、射速、Boss 强度、刷怪间隔）：不做自动化测试，试玩后改 `shared.js` 单点调优
